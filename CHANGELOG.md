# V6 — Evolution over V5

- Expanded project model: video clips, audio/images/shapes/effects, brand fonts and keyframes.
- Preserved V5 presets; expanded to 40 motion presets.
- Added independently timed word track, including optional Whisper word alignment.
- Added timeline editing with trim handles, splitting, duplication, delete and history.
- Added video zoom, playhead keyframes, experimental face reframing and silence cutting.
- Added overlays, imported audio, amplitude-triggered accents and animated sketch elements.
- Added brand kits and batch rendering from local saved projects.
- Added local Whisper, faster-whisper and optional Ollama integration.
- Added tests for project data models; full npm build and MP4 rendering still require local verification.
